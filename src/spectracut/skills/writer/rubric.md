# Writer rubric

The Critic scores each criterion in [0, 1]; the score is the weight-averaged criterion score. The same criteria are in `rubric.json`, which the benchmark runner scores.

## message (weight 2.0)

Does the script carry one clear message that traces to the brief?

## claims (weight 2.0)

Does every on-screen claim and VO line trace to a source in the brief, with no forbidden words?

## hook (weight 1.5)

Do the first seconds hook the stated audience?

## voice (weight 1.0)

Is the copy concise, concrete and natural when read aloud at pace?

## structure (weight 1.0)

Does the structure build to the offer and call to action within the target length?
