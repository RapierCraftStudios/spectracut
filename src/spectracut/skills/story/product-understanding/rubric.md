# Product understanding rubric

- Every feature cites a declared source, and that page supports it.
- Sources are only the supplied pages; no URL is invented.
- The summary is plain and specific, with no hype.
- With a screen map: every proof point and every script beat has a mapping.
- Every route is one of the scanned front-end routes; none is invented.
- Steps are concrete (visit, click, type, scroll, hover, wait on named elements)
  and contain no credentials.
- Interludes are used only for beats, never for a proof point.
