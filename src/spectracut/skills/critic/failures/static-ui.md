# Failure: Static UI

**Seen in:** AlterLab launch trailer, product walkthrough beats

## What went wrong

A screenshot was mapped onto the screen and held for the whole shot. The product looked dead: no cursor, no typing, no state change, so the shot said nothing about what the product does.

## How to detect it

- The screen region is pixel-identical across the shot's frames.
- The shot's beat names an action (search, generate, export) but no capture of that action is used.
- No cursor, focus or state change in the screen region on a contact sheet.

## The fix

Use a live capture of the action the beat describes, or animate the UI: cursor path, typing, a state change, a result landing. Every UI shot shows one visible change that matches its line of VO or on-screen text.
